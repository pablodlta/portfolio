1. Research Motivation, Upstream Foundations & The CAD API Context Collapse

Commercial generative AI models (Midjourney, CSM AI, Sloyd AI) produce non-manifold visual meshes without feature trees, parametric constraints, or machinable tangencies, making them completely useless for mechanical production. Concurrently, attempting to connect an LLM directly to the raw SolidWorks COM API fails due to API context collapse: exposing thousands of COM methods and objects blows token windows, incurs massive API costs, and triggers hallucinated method calls.

The architectural foundation originates from the open-source bridge eyfel/mcp-server-solidworks, which originally connected the SolidWorks API into Claude-compatible context streams. However, rigorous shop-floor and laboratory evaluation revealed that the baseline suffered from fatal concurrency crashes, unhandled COM Single-Threaded Apartment (STA) locks, and a lack of deterministic geometric lowering.

By formalizing the project under Knowledge-Based Engineering (KBE / MOKA methodology), we refactored the pipeline into a decoupled 4-layer architecture governed by a declarative Design Intermediate Representation (Feature Graph IR). Crucially, empirical testing revealed that local open weights (like Qwen 2.5 Coder 7B) lack sufficient spatial intelligence to formulate 3D geometry from raw natural language prompts. However, when the spatial breakdown is guided (initially validated and verified through ChatGPT), Qwen outputs flawless, valid JSON AST. We are currently benchmarking across multiple LLM models (ChatGPT, Claude 3.5 Sonnet, and local Qwen 2.5) to quantify spatial reasoning accuracy, error rates, and token budgets.

2. Physical Distributed Infrastructure: 2-Node Local Area Network

To eliminate reliance on proprietary cloud APIs (ChatGPT, Claude) and guarantee total data confidentiality without token metering, the system was physically deployed across a dedicated 2-machine local area network (LAN):

MACHINE 1: INFERENCE SERVER ("THE BRAIN")
  • • Engine: Local Ollama Server (OLLAMA_HOST=0.0.0.0:11434)
  • • Model: Qwen 2.5 Coder 7B (quantized in 8 GB VRAM)
  • • Workload: Generates strict JSON Feature Graph AST
  • • Cost & Privacy: Zero recurring token cost, 100% on-premise IP
MACHINE 2: CAD WORKSTATION ("THE HANDS")
  • • CAD Host: Active SolidWorks 2025/2026 workstation
  • • Execution Host: SolidworksExecution.exe on C# .NET 4.8
  • • Thread Safety: Dedicated Single-Threaded Apartment (STA)
  • • Python Runtime: Dedicated .venv-qwen running pycompiler

4. Real Engineering Bottlenecks & Experimental Learnings

Real laboratory testing against local models revealed critical geometric bottlenecks that conventional demos conceal:

A. The Topological Naming Problem & Face Resolution

In resolver.py (v0), face selection was restricted to top faces (n̂ · ĵ ≥ 0.9). When Qwen attempted an L-bracket via orthogonal extrusions on lateral faces, the system could not resolve the perpendicular face, causing infinite loops. Solved by designing a durable reference resolver tracking topological entity IDs across FeatureTree rebuilds.

B. Multi-Body Scoping & Parameter Lowering Truncation

When modeling stepped shafts on offset planes, SolidWorks temporarily instantiates disconnected bodies. In SolidWorksService.Features.cs, FeatureCut4 had UseFeatScope = true enabled, stopping a 90 mm hole prematurely at 30 mm at the first body boundary. Patched by enforcing AllBodies = true and updating lowering.py to support explicit blind depth end-conditions.

C. 2D Drawing Discretization & Silent Degradation

Ingesting shop drawings in dxf_read.py failed when encountering SPLINE entities and exploded dimension annotations, producing 0 closed loops and silently falling back to a dummy bounding box. Solved by implementing chordal spline discretization into polyline segments and strict bounding-box validation guardrails.

D. Spatial Intelligence & Multi-LLM Benchmarking: Cloud vs. Local SLMs

Frontier cloud models (ChatGPT, Claude 3.5 Sonnet) possess high spatial intuition to interpret unstructured natural language geometry, but incur token latencies, recurring API fees, and vendor lock-in. Conversely, local open-weight SLMs (Qwen 2.5 Coder 7B) initially struggle with unguided 3D spatial decomposition, yet when provided with structured spatial guidance, they generate 100% syntactically valid Feature Graph AST JSON. We are actively conducting quantitative benchmarking across multiple LLM models to measure spatial accuracy, syntactic error rates, and token consumption budgets.

5. The Strategic Vector: Industrial Domain-Specific MCP Generator

A universal 80-tool MCP server fails in production: it induces token bloat, causes context collapse, and allows LLMs to suggest unmanufacturable geometry (zero-draft injection parts, impossible bend radii). Factories do not manufacture arbitrary mathematical solids; they operate within bounded solution spaces dictated by machine tooling and company know-how.

// The Industrial MCP Meta-Compiler Architecture
1. Know-How Ingestion Extracts plant DFM rules (mold draft, tooling cutter radii, K-factors, ERP article codes, corporate title blocks).
2. Meta-Compiling Server Scaffolds a bespoke MCP server with domain-restricted IR schemas (recipe://usage/empresa_x) and composite tools (create_sheetmetal_enclosure).
3. Automated Factory Output Emits full deliverable bundle: 3D SLDPRT/SLDASM, STEP/IGES, dimensioned 2D PDF/DWG, unfolded DXF flat pattern, and ERP BOM.

Ashby Multi-Objective Material Screening

Using CES EduPack / Ashby charts, candidate elastomers were systematically evaluated across tensile strength, elongation at break, tear propagation resistance, and toxicity:

  • Natural Rubber: Eliminated due to rapid ozone/UV degradation and allergenic latex proteins.
  • Polyamide (Nylon 6/6): Eliminated because high flexural modulus (>2.5 GPa) causes tooth fractures and sharp ingestion shards.
  • Silicones & Soft TPEs: Eliminated due to low tear strength (<25 kN/m) leading to rapid bite punctures.
  • Selected Material: Aliphatic Ether-based TPU (Shore A80), providing 45 MPa tensile strength, >550% elongation, and 100% regrind circularity.
